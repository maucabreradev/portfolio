## 📌 Descripción

Portafolio técnico profesional desarrollado como parte de la evaluación del módulo **"Desarrollo de Portafolio de un Producto Digital"** del programa **Prepárate para el Mercado Laboral**.

Portafolio construido completamente con **HTML5, CSS3 y JavaScript** (sin frameworks). Presenta 3 proyectos reales, un caso de estudio técnico detallado, selector de idioma y sistema de tema oscuro/claro.

## 📖 Caso de Estudio: Biblioteca Digital UNTEC

Análisis técnico detallado con los 8 puntos requeridos por la evaluación:

1. **Descripción** — Sistema web de gestión bibliotecaria con MVC estricto
2. **Desafío principal** — Concurrencia de préstamos, consistencia de inventario multi-rol, integridad transaccional sin ORM
3. **Solución propuesta** — MVC con Servlets, JSP+JSTL, DAO con JDBC, PreparedStatement, transacciones ACID
4. **Herramientas técnicas** — Java 8+, Java EE 8, Tomcat 9, MySQL 8.0, Eclipse, Bootstrap 5
5. **Principales aprendizajes** — Singleton JDBC, HttpSession, AuthFilter, gestión de sesiones, separación de responsabilidades
6. **Métricas de impacto** — 24 tests JUnit 5 (100% aprobación), 0 vulnerabilidades SQL, 2 roles de usuario
7. **Habilidades técnicas aplicadas** — Java EE, Servlets, JSP, JSTL, JDBC, MySQL, MVC, Singleton, AuthFilter, JUnit 5
8. **Justificación** — Demuestra dominio del ecosistema Java empresarial más allá de Spring Boot
